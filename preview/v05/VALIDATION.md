# v0.5 复核记录

日期：2026-10-19。范围：独立静态样式稿，无后端调用。

## 浏览器实测

Chrome，桌面 1440×1000、窄屏 480×800。

- 深浅色正文、右栏分组、横向快捷操作与文件条目可读；文件条目可切换卡片对照，文件入口及 Esc 关闭弹窗正常。
- 铃铛自动模式连续六次采样观察到方案 3、1、3、3、2、2；本体 SVG 内容一致，每次至多两个信号片段，结束后为零。
- 固定方案下搜索只有镜圈与柄的派生片段；发送支持 Enter 激活，基础箭身和箭翼不变。
- 16px 铃铛样本只有一个片段，线宽 0.7。
- 动画中关闭模拟动效后片段立即为零；减弱模式无信号片段，键盘仍可展开任务。
- 窄屏样本可点击并产生两个片段；浏览器没有捕获到 console error。

## 自动化覆盖

`node --test tests/signal-motion.test.cjs`：9/9 通过。覆盖全部图标的路径来源、大小/线宽/时长边界、四种方案、同次悬停/聚焦合并、替换效果、旧计时器竞态、拖离/失焦/禁用/移除/关闭/系统减少动态效果后的清理，以及禁止本体旧形变规则。

拖离取消和系统减少动态效果的生命周期由模拟事件/计时器单元测试覆盖，本轮未以操作系统鼠标拖拽或系统偏好切换另行实测。键盘激活、减弱和关闭模式已在浏览器实测。

语法检查、便携静态资源检查、`git diff --check` 通过；`versions/` 无修改。

## 对照方式

- `before-light.png` / `after-light.png`：同一 1440×1000 视口，浅色静态对话页。
- `before-dark.png` / `after-dark.png`：同一视口，深色静态对话页。
- `narrow-dark.png`：480×800 深色对话页。
- `narrow-light.png`：480×800 浅色动效样本页。
- 打开 `/#motion`，用“方案一”至“方案四”固定采样；铃铛、搜索、发送依次位于前三区。每组左侧为静态本体，右侧可反复点击或键盘激活。“自动”用于观察有限变化。
