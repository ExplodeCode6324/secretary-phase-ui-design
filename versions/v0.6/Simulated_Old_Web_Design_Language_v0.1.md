# 被模拟的旧互联网

设计规范 · 当前修订 v0.6 · 2026-10-19

文件名沿用以兼容已有链接。当前以 v0.5 为工作基础，保留 Master 确认的 v0.3 三栏空间布局、页面组织与主要操作流程。历史仅保留 v0.3 基准版与 v0.5 快照；当前入口为 v0.6。

**静态界面保持清楚、平直、适合长期阅读的网页秩序；交互时，由显示层短暂呈现采样、错位与重绘的痕迹。被模拟的基础对象保持稳定。**

## 1. 工作边界与布局

本项目是独立静态设计稿，不是生产前端；没有后端连接、真实业务执行或正式技术选型。所有消息、任务、通知及授权都是示例。框架、桌面壳与后端接入等待 Master 决定。

| 区域 | 保留的结构 |
| --- | --- |
| 左侧导航 | 196 px；较窄窗口 166 px；名称与图标 |
| 顶部工具条 | 76 px；位置、主题、动效开关、搜索和通知 |
| 内容区 | 默认外边距 36 px；文档式段落和表格 |
| 对话 | 时间线、角色、姓名与时间；底部输入区 |
| 右侧补充栏 | 235 px；任务、近期产物、快捷操作 |
| 窄窗口 | 850 px 以下收起补充栏；600 px 以下导航仅留图标 |

本轮只调整组内和组间的层级，不全局压缩留白，不改变三栏比例。页面标题保持原有标题区的留白；移除冗余内容后不以新口号填补。

## 2. 静态层级

### 分割线

保留侧栏与主区边界、时间线必要分隔、输入框与按钮边界、键盘焦点、必要表格行线和少量识别性蓝色标记。

右栏三个小节标题不再加短横线，用字重、标题到内容的距离及小节间距分组。`.section-label` 不绘制底线，`.quiet-note` 不绘制顶线，说明区域不被重复切分。不将所有线统一加粗、变淡或改成虚线。

### 文字与身份

产品名只保留侧栏品牌及真实对话角色。内容区标题使用当前页面名称。删除 `heading()` 中的重复英文眉题，以及右栏 `RECENT`、`QUICK` 等同义标签；侧栏只保留一条工作空间说明。数量、时间、状态和文件类型继续显示。

右栏条目和操作使用 14 px，元信息 12 px；使用清楚的无衬线字体，不通过宽字距和小字制造精致标签感。正文维持已有可读性，等宽字体继续用于时间、编号或路径。

### 文件条目与快捷操作

快捷操作保持原位置与功能，改为横向“图标＋文字”的操作项。对话产物默认作为文件条目：无独立底色与完整外框，可点击文件名带下划线，类型与时间紧邻显示。

文件条目是局部试稿；“对照卡片”仅切换本条目的包装，文件名和操作保持相同。判断依据是文件识别及入口清楚程度，不将卡片形式视为一概禁止。

## 3. 本体与信号层

| 层 | 包含内容 | 规则 |
| --- | --- | --- |
| 本体层 `.icon-body` | 原始轮廓、笔画、基准线宽与锚点 | 全程完整可读，不做装饰性变形、弹跳、缩放或部件脱离 |
| 交互结构 | 控件边界、焦点、选中、实际展开区域 | 反映真实状态；布局和点击位置不因装饰而漂移 |
| 信号层 `.signal-layer` | 从本体精确路径派生的局部线段 | 允许短暂位移、显隐、不同线宽及独立归位/消隐；不承担唯一状态语义 |

`geometry` 分成 `body` 与 `regions`：前者只含静态可见路径，后者引用本体路径编号与归一化片段范围。铃铛外侧辅助线、搜索十字、发送拖尾等不属于本体，不作为新的静态路径补回。

本体使用 24×24 坐标、统一 1.5 基准笔画。除对话发送键外，不对 `.icon-body` 或 `.part` 施加装饰动画。对话发送键按 Master 要求保留基准版箭身收放、箭翼前行及回位的 850ms 动效；它是唯一明确例外，取消与关闭仍立即复位。除上述发送键例外，悬停、聚焦、按下、释放期间轮廓、比例、笔画位置和视觉重量不变。按下可用稳定颜色或边界回应，信号层先清理/对齐。

真实状态变化不受此限制：真实勾选、展开方向和滑块数值可改变；导航里的设置图标不模拟滑块移动。文字、光标、输入法和点击区域始终稳定。

## 4. 有限采样与图标区域

提供四种非对称方案，每次交互开始时选定一次。每个控件只选择一个图标及一批片段。22–32 px 图标最多两段，18 px 及以下一段；不堆积完整复制轮廓。

| 方案 | 先后与退场 |
| --- | --- |
| 一 | 浅蓝先、蓝色后；一段对齐、一段消隐 |
| 二 | 浅蓝短段先、蓝色另一局部后；分别归位/消隐 |
| 三 | 短段先消隐，另一段稍晚对齐 |
| 四 | 两种颜色错时出现，不同时结束 |

每段持续约 260–420 ms，延迟约 0–178 ms，单批最长约 550 ms。偏移根据实际显示尺寸控制：小尺寸约 1.2 CSS px，22–24 px 约 4 px，32 px 不超过约 6.7 px。双片段每次随机分配一粗一细：细线为 0.7 或 1.0，粗线为 2.4 或 2.8 SVG 单位；小图标不超过 1.0。线宽直接设置在片段的 `stroke-width`，不缩放图标。

四种方案改变采样区域、方向、时序、线宽和退场方式；正常触发可重复选中同一方案。演示页可固定方案一至四以便复核区域及节奏；片段长短和粗细归属仍在每次开始时随机选定。不逐帧随机，不持续制造噪声，不无限循环。

| 图标 | 可采样区域与信号表现 |
| --- | --- |
| 通知 | 铃侧短轮廓、底缘及铃舌路径的局部；本体与铃舌原位不动 |
| 搜索 | 圆环局部与柄端；无放大、十字或柄脱离 |
| 发送 | 通用样本采样箭身及箭翼；实际发送键保留基准版箭头投射与复位 |
| 对话 | 气泡右边缘、底缘与文字短线的局部 |
| 任务 | 夹板边缘和勾选短段；夹板和勾选本体不动 |
| 记忆 | 书脊、页外缘的局部；不抽页 |
| 产物 | 纸页边与折角轮廓；不展开折角 |
| 设置 | 轨道和调节点局部；节点不滑动 |
| 创建 | 横纵笔画端部；交点不伸缩 |
| 动效 | 两层窗口的边缘；窗口本体不拆开 |

铃铛的方案一示例：一侧短轮廓以浅蓝先错开，底缘另一片段稍后以不同线宽出现。片段分别归位或消隐，最终只留下完整静态图标。

## 5. 交互生命周期与真实状态

- 悬停、键盘聚焦各触发一次轻量采样，同一次接触的悬停与聚焦合并，不重置刚开始的效果。
- 按下不缩小本体；清理当前信号，并保留原生按下反馈。
- 有效激活立即执行原有动作，同时替换为一次新反馈。装饰监听不调用 click、不阻止原生激活、不等待动画完成。
- 每个控件只有一个活跃效果记录，统一管理片段动画、CSS 反馈和清理计时器；替换先取消旧记录。旧回调不能清理新的效果。
- 移出、失焦、拖离取消、禁用、节点移除、窗口失焦及动画中关闭动效均清理片段和计时器。
- 关闭、减弱、线稿及系统减少动态效果模式不产生信号；重新开启不补播旧事件。
- 信号层不拦截指针；整个图标装饰对辅助技术隐藏，控件名称由原生按钮或链接提供。

成功、失败、处理中继续使用真实文字和状态图形。颜色归位与采样结束都不等同于业务成功。禁用控件不采样；焦点框和选中态持续稳定。

## 6. 页面、表单、主题与颜色

页面保留分段显影；列表沿原行展开/收束，关闭动效时立即变更；输入框仅边界采样，正文和输入法不重绘；按钮轮廓采样与业务动作独立。同页筛选或提交不重播整页进场。

常规交互使用蓝色与浅蓝。红色只用于失败、重大设置变更和重点标记，并同时提供文字或图形。普通导航、头像、通知圆点不使用红色装饰。

| 角色 | 浅色 | 深色 |
| --- | --- | --- |
| 页面 | `#F5F2EA` | `#1E2227` |
| 表面 | `#FFFCF6` | `#252A30` |
| 正文 | `#262B31` | `#E0E4E8` |
| 蓝色 | `#285EA6` | `#79ACD9` |
| 浅蓝 | `#8BBDE0` | `#B1D5EC` |
| 红色 | `#B84550` | `#ED8791` |

深浅色仅改变色值，不改变布局。主题通过 localStorage 保存；存储不可用仍可在当前页切换。减少动态效果后功能、状态和控制入口保持完整。

## 7. 复核入口

`index.html#motion` 提供静态本体/信号采样对照、四种固定方案、自动变化与 16 px 小尺寸样本。对话页提供文件条目/卡片的局部对照。v0.5 截图在 `preview/v05/`，v0.6 截图在 `preview/v06/`。

人工复核包含深浅色、窄屏、多次触发、按下拖离、键盘激活、动画中关闭动效和列表操作。自动检查验证参数边界与清理生命周期；不将其描述为真实业务验收。

原始概念图保留原色、原构图；历史 `versions` 可含旧动作规则，当前实现和本文为现行约定。不覆盖历史文件来消除差异。
