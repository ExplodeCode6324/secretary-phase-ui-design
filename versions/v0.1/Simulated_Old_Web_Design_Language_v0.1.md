# 被模拟的旧互联网
## 设计语言草案 · v0.1

日期：2026-10-19  
理念基线：《未来媒介中的旧互联网：设计理念文档 v0.1》  
状态：本地样式探索稿；布局、视觉与动效供 Master 复核。下文参数为首轮调校值。

> **用旧网页的方式组织信息，用错版的方式暴露媒介，用直接、可靠的响应表达控制权。**

本规范内部可暂称「错版界面」，这个名称不需要出现在应用里。它不是旧操作系统复刻，也不是把故障滤镜铺在现代卡片界面上。

## 1. 静态骨架：页面优先，容器退后

### 1.1 信息组织

主要对象是页面、栏目、段落、条目、页签、工具条和批注。优先用位置、留白、字重与细分隔线建立层级，不把每一块内容装进卡片。

借用古早个人站点和独立博客的内容组织方式：标题有位置，导航有秩序，链接像链接，正文是页面的主体。不是复制 Windows 95，也不是制作科幻仪表盘。

一个内容区通常按「小标题／必要元信息 → 内容 → 就近操作」组织。只有确实需要独立操作或独立滚动的对象，才增加自己的容器。

### 1.2 形状与边界

结构容器以平直边缘为主，圆角为 0–2；浮层可以放宽至 4。圆形继续用于适合圆形的符号或控件，不为反对圆角而强行把一切切成锐角。

普通分区只用细线或留白。可操作控件的边界比装饰分隔线清楚。默认不使用大面积玻璃模糊、柔软投影、发光描边和多层渐变。

需要表达前后关系时，优先尝试 1–2 个逻辑像素的实色偏移边，而不是厚重的拟物高光。不过，普通页面仍应以平整为主，不能让所有区域看起来都悬浮起来。

### 1.3 首轮基础参数

以下尺寸按 1× 设计稿的逻辑像素计，不是设备的物理像素。不同平台需要再做字号与点击区域的适配。

| 项目 | 初始建议 |
| --- | --- |
| 间距节奏 | 4、8、12、16、24、32；页面外边距另按窗口尺寸调整 |
| 正文 | 15–16，行高约 1.6；使用清楚的无衬线字体 |
| 页面标题 | 22–26，中等或半粗字重；避免巨大的宣传标题 |
| 工具栏与导航 | 13–14；视觉紧凑不等于缩小实际点击区域 |
| 次要元信息 | 12–13；不能用极淡的小字隐藏重要信息 |
| 装饰分隔线 | 1；不单独承担控件识别和状态表达 |
| 控件边界／焦点 | 1–2；焦点必须有稳定、清楚的标识 |
| 默认圆角 | 0–2；少数浮层最多先试 4 |

等宽字体只用于时间、编号、路径和代码。中文正文不做像素化，不通过低清晰度和全屏等宽字制造复古感。

## 2. 色彩：中性色负责工作，双色负责揭示层次

常规交互采用蓝色与浅蓝色。红色仅用于失败、重大设置变更及重点标记，不作为日常装饰色。

### 2.1 暖白、墨色、蓝与浅蓝的基准方案

| 角色 | 示例色值 | 用途 |
| --- | --- | --- |
| 页面底色 | `#F5F2EA` | 略暖的浅色背景；保持干净，不铺纸纹 |
| 轻提亮表面 | `#FFFCF6` | 输入区、菜单等需要轻微区分的表面 |
| 主要文字 | `#262B31` | 正文、图标本体、重要标题 |
| 次要文字 | `#62676D` | 时间与辅助说明，不承担弱化重要状态的任务 |
| 装饰分隔线 | `#CAC5BB` | 非交互性的栏目分界 |
| 控件边界 | `#7A7F84` | 必须清楚可辨的输入框和控件轮廓 |
| A 色层 | `#285EA6` | 蓝色；链接、选中标识及部分偏移边 |
| B 色层 | `#8BBDE0` | 浅蓝色；与 A 色形成局部错版关系 |
| 语义强调 | `#B84550` | 仅用于失败、重大设置变更、重点标记 |

整屏以中性色为绝对主体，蓝与浅蓝只占少量面积。页面应当先让人看到排版，再看到色层。

红色不用于普通导航、头像、按钮边缘与通知圆点。失败、重大设置变更、重点标记使用红色时，必须同时提供文字或形状标识。蓝与浅蓝也不单独代表成功。

### 2.2 静态时仍保留一点身份

默认静态下可以只在一两处留下极轻的错版线索，例如标题下方分隔线的一小段、当前页签标记的外缘。不要让每条边框、每个字和每个图标都带重影。

这点静态线索的作用是让页面不至于成为完全普通的旧网页；它不是把交互过程永久冻结在屏幕上。

## 3. 共同构造：本体可靠，色层可被扰动

所有组件和图标共用同一种构造逻辑。这里的「层」是视觉设计概念，不限定未来代码实现。

| 层 | 保存什么 | 允许怎样变化 |
| --- | --- | --- |
| 本体层 | 文字、图标主体、数值、光标和对象的可识别结构 | 保持清楚；不做彩色复制和随机断裂 |
| 结构层 | 分栏线、控件外框、页签边缘和展开边界 | 可局部揭开、延展或短暂错移；不改变真实点击范围 |
| 色层 | 从同一个轮廓派生的双色边、短线和残像 | 可小幅分离、收束；不能承担唯一的状态信息 |

### 3.1 统一错位规则

首轮只使用一条主要错位轴：水平方向。A 色向左，B 色向右。不要让一个按钮斜着分离、另一个图标旋转散开、第三个面板随机抖动。

静态偏移通常为 0–1；常规交互为 1–2；较明显的结构转换局部最多先试 4。图标越小，偏移越少。这些数值是待验证的视觉幅度，不是不可修改的常数。

横向切片只用于少量结构边缘，不切割正文、数字和输入内容。色层透明度平稳变化，不使用一帧白闪或突然的高亮跳变。

### 3.2 最高权限的呈现

助手名称出现在合适的位置即可，例如对话工作台页首的「PERRI」。不额外堆叠产品 Logo、「主会话」、「Master Control」或 `ROOT ACCESS`。

操作直接，状态如实，控制入口可找到。只有真实存在且有用的信息才显示；不使用虚构进程编号、假日志、解锁仪式或装饰性授权文字。

## 4. 图标：身份来自几何，动态来自同一个轮廓

### 4.1 几何基础

以 24 × 24 的画布起稿，线宽先试 1.5，保持统一的视觉重量。以直线、圆弧和少量简单封闭形为主；放大镜仍可使用圆形，不为了风格刻意扭曲常识符号。

每个图标先完成一个清楚的单色版本。色层必须从这个原型派生，不另外画两套近似但不一致的符号。彩边通常只露出局部，不把整个图标变成三重轮廓。

在 16 的小尺寸下应重新检查形状，必要时减少细节和关闭错位。不能简单缩小一张复杂的故障艺术图。

### 4.2 首批图标设想

| 图标 | 稳定本体 | 可以暴露色层的位置 |
| --- | --- | --- |
| 对话 | 平直为主的简洁气泡，保留清楚的尾部 | 右边缘及底部短线 |
| 任务 | 小方格与两条横线组成的列表 | 方格边缘；任务完成后另显示稳定对勾 |
| 记忆／记录 | 两页或索引页组成的简单结构 | 页面边缘的层叠处 |
| 搜索 | 标准放大镜，圆环与柄比例清楚 | 圆环的一小段；不必额外旋转放大镜 |
| 通知 | 简化铃铛 | 两侧轮廓；用分离与收束回应提醒，不增加独立摇摆规则 |
| 设置 | 两条或三条调节轨道 | 当前调节点附近；不做持续旋转的装饰齿轮 |
| 发送 | 简洁方向箭头 | 箭身／箭头外缘的局部色边 |
| 停止 | 稳定的实心方块 | 一般不需要花哨反馈；优先保证明确可操作 |

图标也有名称、焦点和状态。动态不是它可被识别或可被操作的前提。

## 5. 动态语法：四个动词，而不是一包随机特效

先不扩展到几十种动画。按钮、图标、页签和面板尽量由四个动作组合。

| 动词 | 视觉规则 | 适用语义 | 首轮时间建议 |
| --- | --- | --- | --- |
| 分层 | 局部双色轮廓沿同一轴偏移 1–2 | 接触、按下、局部对象被激活 | 60–100 ms；按住时可以保持稳定的按下态 |
| 对位 | 分离的轮廓收拢到稳定几何位置 | 一段视觉反馈结束 | 100–160 ms；不代表业务已成功 |
| 揭片 | 以平直裁切边揭示新区域，边缘可有一次小幅错移 | 展开面板、切换内容、显示菜单 | 280 ms；仅揭示新内容区域 |
| 扫描 | 一条淡色短线在局部状态区平稳移动 | 系统正在读取、等待或处理 | 单次循环先试 900–1400 ms；不跨越正文 |

时间值只是初始调校值。动作应根据尺寸、输入方式和使用频率调整，不要求所有点击都播放一段完全相同的录像。

### 5.1 按钮不是播放动画，而是跟随真实输入

悬停时色层轻微分离；按下时收拢并保持；在按钮内释放并形成有效激活时立即执行动作，色层回到当前悬停位置，指针移出后对位隐藏。拖离、取消或其他无效激活则返回原状态，不显示成功。

动作的执行不等待动画结束。键盘操作和触摸也必须有对应反馈，不能只有鼠标悬停才发现功能。

连续操作允许打断当前动画并直接进入最新状态，不排队补播。输入每一个字、选择每一段文字和普通滚动，不必触发彩色扰动。

### 5.2 状态与过渡分开定义

- **焦点**用稳定的轮廓表示；初次获得焦点时可以附带一次短暂分层。
- **选中**用稳定的线、字重或位置关系表示；不是让色层一直漂移。
- **处理中**用真实的状态说明与局部指示表示；不知道进度时不伪造百分比。
- **成功或失败**根据真实结果更新；不能仅凭颜色重新对齐，就暗示动作成功。

例如发送消息：用户激活发送按钮，消息立即按应用真实流程提交，按钮的色层随即收束。消息是否已经送达、助手是否仍在处理，由各自的状态标记继续表达。

## 6. 组件映射：同一种媒介，不同的使用职责

| 组件 | 静态形态 | 交互与结果表达 |
| --- | --- | --- |
| 主按钮 | 小圆角或直角的实色按钮；文字清楚；不默认使用蓝与浅蓝渐变 | 悬停时仅外框／图标分层，按下时收拢，移出时对位；处理状态另行显示 |
| 次级操作与链接 | 文字、下划线或轻边界；不全部做成胶囊按钮 | 反馈集中在下划线或短边；文字本身不发生色彩重影 |
| 导航与页签 | 文字目录、平直页签；用短线和字重表示当前项 | 选中标记移动或重绘，内容局部揭片；新选中状态稳定保留 |
| 输入框 | 清楚的矩形边界和稳定底色 | 焦点边框持续可见，获得焦点可短暂分层；光标、输入法候选和正文不受扰动 |
| 对话／内容列表 | 按文档流排版，用角色、时间、留白或细线分隔 | 新条目可局部显现，不把整段历史消息重新动画化 |
| 通知 | 紧凑条带或边栏批注；必要时使用小浮层 | 边缘短暂分层后稳定停留；重要或可操作通知不能只是一闪而过的残像 |
| 弹窗与展开面板 | 克制的边界、清楚的标题和操作；不做大型悬浮玻璃卡 | 揭片进入，退出时简洁收拢；不为动画延迟获取或释放交互焦点 |
| 错误与拒绝 | 明确文字、可识别标记和必要的下一步操作 | 可以有一次局部边界变化；不持续损坏、闪烁或遮盖错误内容 |

用户触发的局部变化应优先获得动态反馈。后台多项任务同时变化时，不让所有条目争相动画；优先保留清楚的静态状态。

## 7. 使用边界：表现层可以失真，操作层不可以

正文、数字、密码、代码和输入内容不做重影，不被扫描条遮挡。装饰线可以很淡，但可操作控件、焦点及重要状态必须清楚可辨。

不能只靠颜色差别表达状态。减少动态效果时，关闭分离、错移和揭片位移，保留稳定的边框、字重、状态文字和必要图标。界面在没有动画时依然要完整可用。

触摸目标可以大于视觉图标；实际点击区域不跟随色层偏移。选中文本、输入法、滚动和焦点管理不因风格而换成难以预测的自创行为。

默认不持续闪烁，不播放背景故障。没有发生值得表达的事情时，屏幕应安静。

## 8. 页面布局与本轮样式稿

本轮输出是可点击的视觉样式稿，不是正式前端工程。`index.html` 直接打开即可预览；所有数据均为示例，交互不调用后端。技术选型、业务接入与桌面壳在后续阶段确定。

### 8.1 概念图取舍

参考 `概念图/整体视觉概念图.PNG` 与 `概念图/动效分镜.PNG`。原图中的红蓝装饰按 Master 本轮调整改为蓝色与浅蓝；原始参考图片保留不变。

保留窄侧栏、文档式对话、近期产物栏、平直输入区、线性图标和蓝与浅蓝边缘标记。概念图中的品牌海报、窗口拼贴与标语不作为应用页面复制；不绘制虚假的窗口控制按钮。右侧批注式区域仅用于补充当前页面的信息。

页面入口根据当前 Core 的对象组织：对话、任务、记忆、产物、待处理、设置。概念图中的通用文件管理、回收站、上传文件不纳入本轮导航。动效样本页只用于设计复核。

### 8.2 基础布局

| 区域 | 设计起点 | 作用 |
| --- | --- | --- |
| 左侧导航 | 196 px；较窄窗口 166 px | 助手名称、主栏目、当前项 |
| 顶部工具条 | 76 px | 位置、搜索、通知 |
| 内容区 | 外边距 36 px | 标题、段落、表格和就近操作 |
| 对话补充栏 | 235 px | 进行中的任务、近期产物、快捷操作 |
| 底部输入区 | 位于对话文档末尾 | 输入、发送与输入方式提示 |
| 窄窗口 | 850 px 以下收起补充栏；600 px 以下侧栏仅留图标 | 保持内容可读，表格允许横向滚动 |

对话不使用聊天气泡。任务和产物使用细线列表；记忆使用文档条目；待处理先展示问题与操作范围；设置按外观与助手配置分组。

### 8.3 动效落地

以分镜图为准，悬停和按下是两个不同阶段：

| 输入 / 状态 | 视觉响应 | 时间 |
| --- | --- | --- |
| 指针进入按钮或图标 | 两侧局部蓝与浅蓝边向外分离，主体不移动 | 160 ms |
| 按下并保持 | 色边向本体收拢，保持到释放 | 100 ms |
| 有效释放 | 立即触发演示动作；色边回到当前悬停位置，移出后隐藏 | 160 ms |
| 拖离后释放 | 取消激活，恢复默认样式 | 160 ms |
| 页面或面板展开 | 平直裁切揭示；仅 3 px 的纵向显现 | 280 ms |
| 处理中 | 状态文字与按钮底部短线扫描 | 1200 ms 循环 |
| 成功 / 失败 | 图形与文字共同表示，结果保留；失败可重试 | 无持续动画 |
| 焦点 | 稳定蓝色外框 | 持续 |

正文不重影，图标本体保持单色。图标色层使用局部结构短边，避免整图复制。页面动画不影响真实点击范围。减少动态效果时移除位移与循环扫描，仍保留状态文本；系统减少动态效果的设置优先。

## 9. 样式复核入口

1. 对话：阅读宽度、段落间距、输入焦点、发送示例、近期产物。
2. 任务：筛选、空状态、详情、创建表单。
3. 记忆：摘要、承诺、世界事实以及来源摘录。
4. 产物：文件列表、文档预览、概念图查看。
5. 待处理：决定选项、授权范围、确认与拒绝。
6. 设置：布局线稿 / 完整样式，标准 / 减弱 / 关闭动效，配置草稿与应用示例。
7. 动效样本：图标悬停、按钮按住与拖离、成功、失败、弹窗和键盘焦点。

复核重点：信息是否清楚；静止时是否安静且有辨识度；输入与视觉反馈是否一致；状态是否可以凭文字识别；减少动效后是否仍完整可用。
